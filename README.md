# LingoBite 🍜

**A menu-translation app that helps travelers confidently order from menus written in a foreign language.**

LingoBite is a UX design case study created for **Cognitive Science 112 (Uncovering the Cognitive Science Behind the User Experience)** at UC Berkeley. It takes a real user problem from initial research through interviews, ideation, prototyping, and usability testing.

---

## The Problem

Travelers and adventurous eaters regularly face menus in languages they can't read, often with no pictures, vague descriptions, and hidden ingredients that matter for allergies and dietary needs. Existing tools like generic photo translators aren't built for menus, so users resort to guessing, asking strangers, or searching dish photos online, spending 10 to 15 minutes per order and still ordering something they don't enjoy.

> *"I took a photo of the menu and put it into Google Translate... only the most popular dishes had pictures, so it was hard to make a well-informed choice."* (user interview)

## The Solution

LingoBite is a menu-first translation app. Point your camera at a menu and get:

- **📷 Scan & crop:** capture a menu photo and crop to just the section you want
- **🌐 Menu translation:** translate between languages with a familiar to/from toggle
- **🥗 Ingredient breakdown:** see what's actually in a dish to avoid allergens and match preferences
- **⭐ Favorites:** save dishes you love for later
- **📝 Ratings & reviews:** rate and note dishes to remember and share

## Design Process

The project followed a structured design-thinking arc:

1. **Understand:** empathy mapping, a needs statement, and user interviews to define the real problem
2. **Explore:** ideation, information architecture, and interactive wireframes/prototype
3. **Materialize:** think-aloud usability tests and concept testing, then iteration based on findings

### What testing revealed

Usability sessions surfaced concrete, actionable issues. The review screen lacked a visible **submit button**, the **crop step** confused users, and the **translation button** was ambiguous, each of which fed directly into design revisions. Testers found the camera scan fast and the favorites feature valuable.
